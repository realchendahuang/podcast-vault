## 结构规范

每一期单集在 `episodes/` 目录下拥有独立的专属文件夹：

```text
episodes/
├── README.md                                          # 本索引表
└── <编号>-<嘉宾/主题-英文短链>/
    ├── README.md                                     # 单集精读导读（速读、心智模型、金句库、时间轴、原视频链接）
    ├── transcript.md                                 # 完整时间戳逐字稿（结构化纯文本）
    └── metadata.json                                 # 机器可读的元数据
```
